# متجر هاشم للطيب — HASHEM LELTEEB

متجر إلكتروني فاخر للعطور المركزة والبخور الملكي واللبان الحوجري الأصيل، مع نظام إدارة طلبات واتساب متطور ولوحة تحكم متكاملة وربط مباشر مع Supabase.

---

## 🌟 الميزات الرئيسية

- 🛍️ **تصفح وشراء المنتجات الملكية**: عطور فاخرة، بخور، لبان حوجري، ومخلطات.
- 📱 **طلب فوري ومطابق عبر WhatsApp**: رسالة طلب منسقة تلقائياً تُرسل إلى رقم المتجر `+96877036097`.
- 💳 **الدفع عبر التحويل البنكي (بنك مسقط)**: إمكانية إدخال رقم الحوالة ورفع صورة إشعار التحويل.
- 🚚 **خيارات الشحن والاستلام**: توصيل لكافة المناطق أو استلام مباشر من الفرع.
- 🎬 **قسم فيديوهات المنتجات (Reels)**: عرض مرئي تفاعلي للمنتجات.
- 👑 **لوحة تحكم شاملة للمدير (`/admin`)**:
  - إدارة وتعديل المنتجات والعروض والأسعار والمخزون.
  - إدارة الأقسام والتصنيفات ورفع صورها.
  - إدارة فروع المتجر وأوقات العمل وأرقام الهواتف وروابط خرائط Google.
  - إعدادات المتجر: تغيير لوجو الموقع، صورة واجهة الهيرو، الشريط الإعلاني، وبيانات بنك مسقط والتواصل.
  - متابعة وإدارة حالات الطلبات والعملاء.

---

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 19, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons, TanStack Start & Router.
- **Backend / Database**: Supabase (PostgreSQL, Auth, Storage, Row Level Security).
- **Typography**: خط Alexandria العربي الملكي مع Tajawal و Plus Jakarta Sans و Cinzel.
